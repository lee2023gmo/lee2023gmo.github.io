Layer normalization（后面统一称为LN）是transformer中多次用到的技术，前不久阅读完原始论文，现在来写一份该论文的阅读笔记

文章的第一部分是一个简单的介绍，介绍了神经网络的强大功能和目前遇见的一个困难：杰出的神经网络往往要花费数天来训练。文章介绍了一种解决的办法：模型并行化-------将一个模型拆解到多台机器上进行计算（模型并行）或在多台机器上分别计算不同训练子集的梯度（数据并行），但是这种办法技巧性极高且随着并行程度的提高收益会越来越少。随后又指出名为normalization（归一化）的技巧可以轻松解决这个问题，提出一个已经取得许多成绩的normalization------batch normalization（后面统一称为BN）。此外，作者指出BN的劣势：作用于RNN时需要为每个时间步分别计算并存储统计量，且测试序列长度超过训练序列时无法处理。此外，在小批量训练中，由于批量过小导致平均值和方差等统计量的不稳定也会造成负面影响。这一部分的最后作者指出LN这一技巧，并说明这一技巧在RNN中有着既提速又提质的强大功能。

第二段部分是对BN的进一步介绍，指出深层神经网络中，一层的梯度十分依赖上一层的输出，导致神经网络训练时对参数十分敏感，训练过程不稳定，因此引入BN，通过对数据的重新缩放和平移，来达到解决上述不稳定的问题：āᵢˡ = (gᵢˡ / σᵢˡ)(aᵢˡ − μᵢˡ)，μᵢˡ = E_{x∼P(x)}[aᵢˡ]，σᵢˡ = √( E_{x∼P(x)}[(aᵢˡ − μᵢˡ)²] )，aᵢˡ = wᵢˡ hˡ，hᵢˡ⁺¹ = f(aᵢˡ + bᵢˡ) 。其中gᵢˡ和bᵢˡ是可学习的参数（增益参数和偏置参数）。值得一提的是，虽然推理时我们采用的μ和σ是用训练过程中积累的滑动平均值（详细计算方法可以询问ai），但在训练时这是做不到的，于是我们采用当前batch中的所有数据来估计μ和σ，这就对训练过程中的batch size有了要求。

第三部分正式进入有关LN的详细讨论，最基本的公式和BN一致āᵢˡ = (gᵢˡ / σᵢˡ)(aᵢˡ − μᵢˡ)，只不过μ和σ的公式改变了μˡ = (1/H) Σᵢ₌₁ᴴ aᵢˡ，σˡ = √( (1/H) Σᵢ₌₁ᴴ (aᵢˡ − μˡ)² )，变成了这一层所有线性神经元输出的平均数和标准差（就是在线性变换之后，激活函数之前的那组数据）。然后说明了LN如何解决BN在RNN中所遇到的问题，（公式变为hₜ = f( (g / σₜ) ⊙ (aₜ − μₜ) + b )，μₜ = (1/H) Σᵢ₌₁ᴴ aₜⁱ，σₜ = √( (1/H) Σᵢ₌₁ᴴ (aₜⁱ − μₜ)² )，aₜ = Wₕₕ hₜ₋₁ + Wₓₕ xₜ）由于LN中用到的μ和σ只依赖于当前层的线性部分的输出，再通过所有时间步共享增益参数和偏置参数来实现对任意长度的序列的处理。并介绍了LN的另一个好处：LN使得模型对输入的尺度缩放（即同时乘以某个数）不敏感（因为输入的尺度缩放会导致方差的相同尺度的缩放，在LN的作用下最终被抵消），从而避免了RNN中隐藏状态随着时间步的变化不断变小或变大而导致的梯度消失和梯度爆炸的问题，使得训练更加稳定。

第四部分则是对一些相关工作的介绍，包括BN和weight normalization(后面统一称为WN)。并介绍了一些关于BN用于RNN的相关研究，指出模型取得最佳性能的方式是为每个时间步保留独立的统计参数，且将增益参数初始化为0.1而非1也能取得不错的成果。而WN的基本公式也是āᵢˡ = (gᵢˡ / σᵢˡ)(aᵢˡ − μᵢˡ)，只不过在WN中μ和σ分别取0和wᵢˡ.norm()。此外，作者还指出LN跟BN和WN之间的一个重要区别：BN和WN本质上还是重参数化，不会改变模型所覆盖的输入-输出关系集合，但LN不是。

第五部分是文章最难的一部分，对LN的作用进行了数学上的理论分析，包括不变性方面和黎曼几何曲率方面（说实话讲黎曼几何的那部分我也没怎么看懂，但还是写一点自己的浅薄理解吧）。

文章首先比较了LN，BN，WN各自具有的不变性。首先，我们明确三者之间有一个共同的形式：hᵢ = f( (gᵢ / σᵢ) (aᵢ − µᵢ) + bᵢ )。三者之间主要的区别就是μ和σ的选取方式不同。然后我们来分析三者之间各自具有的不变性：一，关于权重矩阵缩放的不变性，容易发现三者都具有该不变性；二，关于权重矩阵平移的不变性，经过简单的计算就知道只有LN有该不变性；三，关于某个权重向量缩放的不变性，也是计算一下就知道只有LN不具有该不变性，其他都具有；四，关于训练数据集整体进行缩放的不变性，只有WN不具有该不变性；五，关于训练数据集整体进行平移的不变性，只有BN具有该不变性；六，关于某个训练数据单独进行缩放的不变性，只有LN具有该不变性。从以上分析中我们就可以看到，LN的不变性多于WN，与BN相当，且在对RNN更重要的单个训练样本缩放上具有不变性，因此在训练时更不容易因为某些无关紧要的变化对模型输出造成重大影响，使得训练过程更加稳定，从而达到加速收敛的效果。

接下来的一部分中，作者从俩个角度讲解了为什么LN能够有效。一是随着权重向量的增长，归一化能起到一个隐式学习率降低的作用，这是因为fisher矩阵被σ**2控制，当权重变大2倍时，这个方向的曲率反而会下降，起到隐式的学习率降低的作用，从而实现隐式的早停，加快模型的收敛。二是作者证明了归一化中的增益参数的学习只取决于预测误差的大小，而与输入数据的缩放幅度无关（证明我看不懂，就不讲了，详细可以看原文附录），从而取得了更好的鲁棒性。
